RxJS · pipe() fonctionne comme un filtre à eau
Chaque opérateur est une couche de la cartouche : il reçoit la valeur de la couche précédente, la traite, et passe le résultat à la suivante.
source$Observable source
fermé
1
filter(x => x > 15)
ne laisse passer que les valeurs supérieures à 15
2
map(x => x * 2)
transforme chaque valeur reçue
3
take(2)
laisse passer 2 valeurs, puis termine le flux
0 / 2
valeurs écartées
resultat$ce que reçoit l'abonné
complete
// source$ émet 10, 20, 5, 30, 40 (une valeur par seconde)
const resultat$ = source$.pipe(
filter(x => x > 15),
map(x => x * 2),
take(2)
);
resultat$.subscribe({
next: v => console.log(v),
complete: () => console.log('complete')
});
